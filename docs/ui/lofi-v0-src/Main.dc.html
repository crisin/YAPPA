SHELL-SYSTEM v0

Eine Shell, viele Module

Neue Features kommen als Modul in die Shell. Die Shell selbst ändert sich nicht.

A
Modul-Rail. Eine Ebene: Voice, später Hub, Games, Tools. Icon plus Label, nie nur Icon. Ab 7 Modulen: anpinnen und „Mehr“.
B
Kontext-Sidebar. Gehört dem Modul. Oben der Space („Die Gang“); der Umschalter wird erst aktiv, wenn es mehr als einen Server gibt.
C
Stage. Inhalt plus eine Aktionsleiste. Primäre Aktionen stehen immer unten in der Stage.
D
Voice-Dock. Gehört der Shell, nicht dem Voice-Modul. Der Call läuft weiter, egal welches Modul offen ist.
E
Topbar und Befehlspalette. Breadcrumb plus Strg K: jeder Channel, jede Person, jede Einstellung, jede Aktion. So skaliert die Navigation für Profis.
F
System-Banner. Ein Slot für alles, was die App betrifft. Maximal einer gleichzeitig, nach Priorität.
G
Inspector. Details und Werkzeuge zur Auswahl (Soundboard, Person, Channel). Nie Pflicht für einen Flow.
